# 云岛歌词 v0.3.6 · 模块化角色与封面修复

## 本版重点

- 修复大封面只显示顶部的问题：原生 SMTC 模块改为按实际图片流长度分块读取，不再截断于 1 MiB。
- 保持事件驱动，不增加周期复查、延时补查或运行时辅助进程。
- 新增角色面板，可选择无角色、水无月萤、水上由岐（校服）及水上由岐（黑裙），并导入、管理多个自定义透明 PNG 角色。
- 新安装默认无角色；旧版有效配置升级后保留水无月萤。
- 没有歌曲时也可打开展开视图；角色面板打开期间临时解除鼠标穿透，关闭后恢复。

## 下载与升级

- `NeteaseIslandLyrics-0.3.6-portable.exe`
- `NeteaseIslandLyrics-0.3.6-portable.exe.sha256`

请先从托盘彻底退出旧版，再运行新版；原有设置与角色数据会保留。运行一次新版可更新随网易云启动的路径。

- 81 项 Node 测试、4 项原生读流测试通过。
- 角色界面、导入管理、旧配置迁移及打包后的大封面显示检查通过。
- 《野百合也有春天》的 5,050,859 字节封面已完成完整读取核验。
