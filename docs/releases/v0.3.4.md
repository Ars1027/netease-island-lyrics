# 云岛歌词 v0.3.4 · 水无月萤版

这是水无月萤主题版的首个公开 GitHub Release，包含完整的 portable 程序、轻量网易云监听器与 SHA-256 校验文件。

## 本版重点

- 修复悬停透明曾经只能由“展开”箭头触发的问题。
- 人物、封面、歌词和胶囊任一区域都能触发 35% 不透明度效果。
- 使用真实窗口 shape 命中，透明舞台和圆角外不会误触。
- 50ms 低频监控只在可见紧凑态运行；单一定时器不会随运行时间累积。
- 保留无闪烁歌词动画、350ms 自动提前、强制置顶、鼠标穿透和随网易云自动启动。

## 升级注意

应用使用单实例锁。请先从托盘菜单彻底退出旧版本，再启动 `v0.3.4`；仅隐藏窗口不会加载新代码。

如果云岛无法识别网易云，请确认 Windows 媒体控制区域能看到当前歌曲。BetterNCM 用户需要安装并启用 SMTC 插件，然后彻底重启网易云音乐。
